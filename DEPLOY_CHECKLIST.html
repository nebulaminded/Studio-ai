Phase 2 — Stripe Setup STRIPE

Phase 3 — Push to GitHub GITHUB
Create a GitHub account & new repo
Go to github.com → Sign up (free) → New repository → Name: studio-ai → Public or Private → Create.
Install Node.js (if not already installed)
Download from nodejs.org → choose the LTS version → install. Then open Terminal (Mac) or Command Prompt (Windows).
Push project files to GitHub
Put all the project files in a folder called studio-ai on your computer, then run:
cd studio-ai npm install git init git add . git commit -m "Studio AI launch" git remote add origin https://github.com/YOUR_USERNAME/studio-ai.git git push -u origin main
Phase 4 — Deploy on Vercel VERCEL
Create Vercel account & import project
Go to vercel.com → Sign up with GitHub → New Project → Import your studio-ai repo → click Deploy.
Add environment variables in Vercel
Vercel Dashboard → your project → Settings → Environment Variables. Add these three:
STRIPE_SECRET_KEY = sk_live_your_key_here STRIPE_PRICE_PRO = price_your_pro_id_here STRIPE_PRICE_TEAM = price_your_team_id_here
Then go to Deployments → Redeploy so the new variables take effect.
Test a payment end-to-end
In Stripe, switch to Test mode first. Use test card 4242 4242 4242 4242, any future date, any CVC.
Click Upgrade in your live app → complete checkout → confirm you land back on the app with Pro unlocked.
Go live & share your URL
Switch Stripe back to Live mode, swap in your live API keys in Vercel, redeploy.
Your app is live at studio-ai.vercel.app — or connect a custom domain in Vercel → Settings → Domains.
